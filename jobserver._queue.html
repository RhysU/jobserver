def deadline_to_timeout(deadline: float) -> float: ¶

Return seconds remaining until deadline, non-negative and finite.

Intended to be paired with timeout_to_deadline(). The result is safe to pass directly to poll()/select() on any platform.

def timeout_to_deadline(timeout: float | None) -> float: ¶

Convert timeout in seconds into a monotonic, absolute deadline.

When timeout is None a large, finite deadline is returned per poll()/select() restrictions.
